# ✏️ TIZA — Tutor Inteligente de Matemáticas para Niños

> **Proyecto presentado para la Coder Cup** > Un tutor matemático accesible, empático y adaptativo impulsado por Inteligencia Artificial (Google Gemini) diseñado para niños y niñas de 6 a 12 años.

---

## 🎯 El Problema y Nuestra Solución

Muchos estudiantes de primaria se frustran al resolver problemas de matemáticas en casa. La mayoría de las herramientas de IA actuales entregan la respuesta numérica de inmediato, impidiendo el desarrollo del pensamiento crítico y el aprendizaje autónomo.

**TIZA** soluciona esto actuando como un maestro paciente y empático:
- ❌ **Regla de Oro:** NUNCA entrega el resultado final.
- 💡 **Metodología Guiada:** Explica la lógica en pasos simples, ofrece pistas orientadoras y propone un ejercicio similar para fijar el aprendizaje.
- 🔊 **Accesibilidad Infantil:** Incluye un lector de voz (TTS) para niños pequeños o con dificultades de lectura.

---

## 🎨 Sistema de Diseño (70s Retro Clean)

Diseñado específicamente para reducir la carga cognitiva de los niños:
- **Crema Vintage (`#F9EFE3`):** Fondo cálido y descansado.
- **Azul Noche (`#18283B`):** Textos de alto contraste y sombras planas de 4px.
- **Naranja Coral (`#E75B44`):** Botones de acción principales.
- **Amarillo Mostaza (`#EEAA3B`):** Pistas y destacados.
- **Verde Teal (`#008B8B`):** Indicador de éxito y práctica.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** Next.js (App Router), React, Tailwind CSS.
- **Inteligencia Artificial:** API de Google Gemini (`gemini-1.5-flash`) con procesamiento multimodal (texto e imágenes).
- **Audio / Accesibilidad:** Web Speech API (`window.speechSynthesis`) configurado en `es-AR` / `es-419`.
